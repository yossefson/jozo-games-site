# JoZo Games

The static website for the JoZo Games studio.

Website: https://jozo.games

Contact: hello@jozo.games

## Publishing

GitHub Pages publishes the root of the `main` branch. There is no build step and no package installation. Changes pushed to `main` are published automatically.

The `CNAME` file sets the custom domain to `jozo.games`. DNS is managed separately in Cloudflare.

## Files

- `index.html`: content and SVG illustrations.
- `style.css`: responsive layout and typography.
- `main.js`: scroll-driven illustration motion in normal document flow, with counterclockwise orbiting balls and reduced-motion support.
- `assets/`: studio wordmark, favicon, locally hosted font, and Orbito product photograph.
- `.nojekyll`: serves the files without Jekyll processing.

The site uses no third-party scripts, analytics, cookies, or backend. Contact links open the visitor's email application. Reduced-motion preferences are respected.

## Assets

The studio wordmark is the original JoZo Games artwork. The Fredoka font is distributed under the SIL Open Font License, included in `assets/fredoka-OFL.txt`. The illustrations are abstract studies inspired by the games, not playable puzzles.

The Orbito product photograph is from FlexiQ's official product page and is credited on the site: https://flexiqgames.com/wp-content/uploads/2023/03/230208-FlexiQ-FXG502-Orbito-WS1-HR-5-logos.jpg
